# Semantic intelligence delivery program

Implement repository understanding, context-selected compiler call tracing and
source-backed change-impact retrieval while preserving exact search, immutable
serving and a pure-Go default runtime.

The reusable work includes isolated compiler capture, verified offline dependency
bundles, context-aware semantic indexes, bounded MCP tools and synthetic or public
source fixtures. Independent comparative quality measurements require separately
maintained corpora, source oracles and access-controlled evaluation records.

Next work: expand independent public holdouts, validate compiler capture coverage,
and evaluate retrieval quality with externally configured datasets. Repository
coverage follows the caller's access and privacy policies.
