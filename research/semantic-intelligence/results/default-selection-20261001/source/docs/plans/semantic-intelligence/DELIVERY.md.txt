## S1 — semantic confidence and serving correctness

Date: 2026-09-30. Status: locally implemented, reviewed and verified; not deployed.

### Delivered behavior

- Hierarchy and DI short-name matches are never stamped Verified/Proven. Unique
  local, language-compatible, single-occurrence targets reach Pattern; ambiguous,
  foreign or shared-context alternatives remain Candidate. Non-type homonyms
  cannot become type bindings.
- Angular owners use repository plus relative path. Selector matches preserve
  alternatives instead of choosing a map-order winner. Unique local conventions
  reach Pattern; ambiguity, shared content and class-name fallback stay Candidate.
- EF query heuristics are at most Pattern; shared contexts remain Candidate.
  Explicit namespace mismatches and foreign-language types cannot become entity
  targets. Explicit `Set<T>()` extraction works without a DbSet-property registry.
- HTTP route shape matches are at most Pattern. Competing compatible destinations
  or shared caller/handler contexts remain Candidate. Known verb mismatch still
  excludes an edge; evidence and diagnostic alternatives are preserved.
- The graph roster includes repository/path contexts and a versioned binding
  policy. Refresh migrates old confidence assignments even without changed bytes;
  context-only changes invalidate facts. Content-only similarity survives that
  policy migration. No public binary graph format migration is needed.
- Graph-enriched MCP context rejects known incompatible corpus fingerprints as
  `snapshot_unavailable`, without returning mixed evidence. Conflicting identities
  are non-cacheable. Same-corpus graph rebuilds and `graph_depth=0` remain usable.
- Agent context preserves lexical/symbol/path retrieval when query-time dense
  retrieval fails, with `dense_unavailable` in structured and text results. Those
  results are non-cacheable, including empty answers. Backend details do not leak;
  cancellation/deadlines remain errors. Strict ranking/evaluation APIs stay strict.
- Dense cosine scoring has a shared process-wide worker budget and exact local
  top-K reduction. It avoids allocating a score per corpus chunk and checks
  cancellation while waiting/scanning/merging. The worker ceiling is GOMAXPROCS
  on first dense query; embedding and offline similarity work are separate.

## S2a — scoped retrieval and paired serving

Date: 2026-09-30. Status: locally implemented; not deployed. This is the first
S2 slice, not completion of semantic identity persistence.

### Delivered behavior

`search_context` accepts intersecting `repo`, `path_prefix`, and `language`
filters. Repository names match persisted identifiers exactly. Paths match literal
slash-separated segments, with an optional trailing slash. Languages use canonical
lowercase extension categories advertised in the input schema. For example:

```json
{"name":"search_context","arguments":{"query":"OrderStore","repo":"orders","path_prefix":"src","language":"csharp","format":"structured"}}
```

Filtering applies before arm ranking and top-K, including dense chunk selection.
Shared blobs retain matching references and matching path scores. Structured
results echo the applied filters in `summary.scope`. Invalid scopes return
`invalid_scope`; custom providers lacking scope support return
`scope_unsupported` instead of silently widening retrieval. Empty scope preserves
the existing unscoped path.

Graph anchors require a matching source occurrence. Incoming and outgoing
traversal reject outside nodes before they enter the frontier or output caps.
Shared graph nodes display a matching location. An excluded node cannot bridge
to an otherwise eligible later node. Scope is a retrieval filter, not an access
control boundary or compiler binding guarantee.

Warm HTTP and stdio now lease an immutable source/graph pair through retrieval,
annotation and rendering. Namespace derivation also uses the leased corpus root.
Replacement loading and captured fingerprint validation precede publication;
failed or inconsistent replacements retain the old pair. Existing tool
registrations resolve against the current generation. New requests can use the
replacement while older leases drain; close errors from both components remain
observable. A genuinely absent graph permits source-only serving, while a
malformed existing graph fails preparation. Custom independent adapters retain
the S1 mismatch gate. There is no cross-call snapshot pin.

[ADR 0026](../../adr/0026-semantic-identities-and-scoped-retrieval.md) records the
accepted distinction between content, occurrence and qualified-symbol identities,
evidence provenance and cache dependencies. [S2-PLAN](./S2-PLAN.md) defines the
compiler/SCIP comparison and subsequent persistence gates. These design contracts
do not imply that semantic IDs have been persisted or that compiler bindings work.

### Evidence and limits

HTTP tests use real deduped source shards: matching occurrences survive shared
bytes across repositories, paths and languages; 96 outside ranking decoys and
40 outside graph targets cannot consume the scoped result capacity. Unit tests
cover dense pre-cap filtering against a serial oracle, scope concurrency,
incoming/outgoing excluded bridges, source-location selection, request release
on errors, and leased namespace provenance. Lifecycle tests hold a request across
publication and verify old-response coherence, new-reader availability, current
tool routing, preparation failure, cancellation and shutdown.

BM25 statistics remain corpus-global. Repository scope uses a prebuilt blob
catalog; path/language scope without a repository scans location metadata.
Scoring indexes and source bytes are shared. A synthetic membership-only benchmark
with 10,000 blobs across 100 repositories measured about 9 microseconds/19 KB for
one repository's 100 blobs and 1.20 milliseconds/2.62 MB for a path-only scope
matching all blobs (M5 Max, 10 iterations). These are not end-to-end latency or
private-corpus acceptance measurements.

Paired serving validates known fingerprints and reader lifetimes, not legacy
artifacts with absent identity or an entire transactional filesystem publication.
Use immutable validated generation directories for rollout.
