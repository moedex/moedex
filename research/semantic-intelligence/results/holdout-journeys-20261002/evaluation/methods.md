Evaluation method and qualifications

- The six prompts and initial 30 source-derived atoms were frozen before product queries. A fresh source-only reviewer verified all 258 source hashes and all 44 original citation ranges; eight atom wording/evidence amendments and common partial-credit clarification were adopted before capture. The six task prompts and atom count did not change. Complete review and before/after decisions are retained.
- The selected Debug/net10.0 build uses no custom project constants. The SDK is 10.0.401, unchanged worker18 uses Roslyn5.9.0.0. Normal build and offline restore pass, with nine compatibility warnings. Frozen semantic capture subsequently fails on workspace diagnostics containing those warnings. The capture failure is retained; no warning suppression, detector changes, source rewrites or friendlier commit were used.
- Before any solver launched, the executed arm was explicitly changed to native source-only serving: graph=false, no compiler artifact, embed=none. It indexes 252 files from the same pinned 258-file repository (non-indexable files excluded by normal indexing). This is a source-only holdout result and a failed compiler-arm setup, not compiler-enabled acceptance.
- One fresh solver per task, one child at a time; the coordinator did not supply paths, symbol IDs or task answers. Solvers received only their task, generic build variant, budgets and logged browser instructions. Each could discover the native 22-tool catalog. The initial catalog is uncharged; every attempted MCP call thereafter is charged, including failures.
- Budgets remain 24 attempted calls, 131072 complete serialized response bytes and 600 seconds from coordinator assignment. The first crossing response is retained, subsequent calls stop. The parent records assignment/completion upper bounds; the view wrapper additionally enforces the assignment deadline for browser activity. Answer submission still requires coordinator timing audit.
- The browser limits displayed stdout to 8192 bytes and offers explicit partial pages, offsets and JSON Pointer selections. Complete wire evidence/accounting remain separate. The view logger retains exact stdout/stderr and timestamps. Hash/reconstruction audits verify that displayed fragments match recorded wire evidence. These logs do not prove model attention or provide full host-tool transcripts.
- The first task encountered sandbox loopback PermissionError before repository evidence; fail-closed unknown transport accounting prevented further calls. Its abstention is retained, with no reset or replacement. Subsequent not-yet-launched tasks explicitly used escalated local-server access from the first call. The original assigned-task denominator and conditional evaluable-task denominator must both be reported; no product failure should be inferred from this infrastructure failure.
- Fresh answer reviewers see the reviewed rubric, their single answer, its displayed evidence and pinned source, but not coordinator scores or other reviews. The coordinator separately scores answers and adjudicates differences, retaining both original scores.
- Agent model settings are inherited defaults, without overrides; exact model build, sampling seed and token consumption are unavailable. Filesystem separation is instruction-based rather than OS-enforced. Solver attestations and logged views are retained, not promoted to proof of enforced isolation.
- The repository/task selection is a small coordinator-chosen holdout, not random sampling, full repository coverage, absence from pretraining, a large-corpus resource benchmark or cross-service generalization. Existing development scores are not pooled. CodeGraph's product arm remains unready and unrun; this establishes no paired competitive win or causal benefit of compiler tools/presentation changes.

- This client supplies a native tools/list catalog and calls tools directly; it does not provide MCP initialize-response server instructions to solvers. Results therefore cover this catalog-based harness rather than every production MCP client onboarding experience.
