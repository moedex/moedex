# Public agent journeys: first development slice

Date: 2026-10-01. Status: **3 of 12 tasks executed; evaluation incomplete**.

The first actual solver runs start with natural-language tasks, the pinned
Sample-Outbox repository label, and the public tool catalog. No symbol IDs,
context IDs, source paths, or scoring labels are supplied. Repository evidence
comes through the production HTTP MCP service with embeddings disabled, using
the unchanged `reverse-outbox` snapshot. This is a small, trained development
corpus, not a heldout or competitive benchmark.

## Frozen inputs and execution

[Protocol v1](results/agent-journeys-20261001/protocol.json), the
[source rubric](results/agent-journeys-20261001/source-rubric.json), and independent
[rubric review](results/agent-journeys-20261001/rubric-review.json) precede execution.
The rubric contains 67 source-linked requirements for 12 unchanged prompts and
hashes all 40 checked-in files. Two reviewers score the completed tasks and retain
their initial judgments plus adjudication.

Three initial attempts failed before any product response because the host
sandbox blocked loopback networking. A separate setup smoke also found that the
subagent-owned server had exited. Those attempts remain archived. The
[infrastructure successor](results/agent-journeys-20261001/protocol-v2.json) keeps
the tasks, rubric, product, and budgets unchanged, makes network escalation
mandatory, and runs the server under the coordinator. One solver is fresh; two
retry only their original task after receiving zero repository evidence.

The host's lifetime agent-thread limit prevented creating the remaining fresh
solvers. Nine tasks remain unexecuted, including every cross-service and contract
impact journey. Completed solvers are not reused on other tasks.

scores differed; adjudication applies the frozen partial-credit rule for broad

agent use of the new compiler discovery tools. Four of the eight requests fail:
three `list_repos` calls and one `read_source` call return “graph tools are closed.”
Successful search lets the solvers recover without supplied IDs.

The runs stay within 24 calls and 131,072 response bytes per task. Exact assignment
timing was not captured reliably, so there is no latency result. The interval from
protocol freeze, before all assignments, to observed completion bounds every run
below 227 seconds, within the 600-second cap. Model tokens, exact model build, and
randomness controls are unavailable. Catalog setup bytes are excluded by protocol;
all attempted MCP requests, including errors, are charged.

## Limits and continuation

The [logged client](agent-journeys/client.py) retains raw request/response bytes,
hashes, an append-only event ledger, and atomic budget reservations. It is an
accounting mechanism, not a host-filesystem sandbox. Solvers attest to following
the allowed evidence paths; complete model/tool-activity transcripts are not
available for independent enforcement auditing. This limitation prevents a claim
of technically isolated evaluation.

CodeGraph's production service remains unavailable because of its private
dependencies and database requirements. There is no paired agent comparison,
competitive win, heldout result, or PROGRAM30 completion. The remaining nine
frozen tasks require fresh solver capacity.

## Separate production correction

Evidence: [separate correction manifest](results/source-only-discovery-20261001/result.json).

The first slice exposed a source-only serving defect: an absent optional graph
created an empty, effectively closed discovery toolset. The correction opens an
immutable source/symbol generation instead. Repository listing, file trees,
symbol listing, and source reads now work; graph-dependent tools report
`graph_unavailable`. Closed-state errors remain distinct. Strict preparation still
rejects existing corrupt graphs, and the standalone MCP fallback also supports
source discovery when the graph is absent.

Full Go tests, vet, and build pass. Focused normal/race tests cover immutable reads
after live-file modification/deletion, snapshot metadata, close, retained leases,
and graph/source reload transitions. A separate native HTTP regression against the
fixed binary passes 14 calls: four source tools plus search, and nine explicit
graph-unavailable responses. It returns 12,609 complete serialized bytes with a
consistent source fingerprint. This scripted regression is not a new agent run;
the original eight-call baseline and its errors remain unchanged.

Source-only startup skips the graph traversal path index. It still loads an eager
symbol catalog, adding memory/work compared with the former empty toolset. No
large-corpus resource guarantee is claimed for this correction; that cost needs a
separate corpus gate before a rollout that depends on it.
